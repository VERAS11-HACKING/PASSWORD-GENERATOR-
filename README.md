# PASSWORD-GENERATOR


A secure password generator application built with Python for the frontend and SQL for the backend. The application generates strong, customizable passwords and stores relevant password data securely in a SQL database.

Features

- Generate strong and random passwords
- Customizable password length and character types
- Python-based user interface
- SQL database integration
- Simple and user-friendly design
- Helps improve password security

Technologies Used

- Frontend: Python
- Backend/Database: SQL
- Language: Python, SQL
